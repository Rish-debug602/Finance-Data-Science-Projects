# Finance & Data Science Portfolio

Welcome to my portfolio of Python-based projects focused on **financial analytics, quantitative finance, risk management, and data science**.

This repository contains projects covering financial markets, fixed income, time series analysis, portfolio risk, dimensionality reduction, and credit risk.

## Projects

### 1. Bond Analysis

Analysis of fixed-income instruments and key bond risk measures, including yield, duration, and convexity.

**Key concepts:** Fixed Income, Duration, Convexity, Yield Analysis, Python

### 2. Time Series Analysis

Analysis of financial time series, including returns, trends, volatility, and statistical relationships.

**Key concepts:** Time Series, Financial Returns, Volatility, Statistical Analysis

### 3. Portfolio Risk Analysis

Portfolio analytics using statistical and simulation-based approaches to assess portfolio risk and optimize portfolio allocation.

**Key concepts:** Portfolio Optimization, Monte Carlo Simulation, VaR, Correlation, Covariance

### 4. PCA & SVD for Financial Data

Application of Principal Component Analysis and Singular Value Decomposition to financial datasets for dimensionality reduction and identification of underlying risk factors.

**Key concepts:** PCA, SVD, Eigenvalues, Eigenvectors, Dimensionality Reduction

### 5. Private Credit Portfolio Surveillance

Development of a Python-based framework for monitoring borrower-level credit characteristics and identifying potential portfolio risk indicators.

**Key concepts:** Credit Risk, Portfolio Surveillance, Risk Monitoring, Feature Engineering
